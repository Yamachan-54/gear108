# コンテンツワークフロー — 週5本を持続するための運用設計

> 毎日1本は持続不可能だが、**週5本（年260本）なら現実的**。
> その前提を設計に組み込む。

## 週次運用テンプレ

| 曜日 | 作業 | 想定時間 |
|------|------|---------|
| 月 | リサーチ＆ネタ選定（5本分の見出し決め） | 1時間 |
| 火 | 1本目（速報・短い記事） | 1時間 |
| 水 | 2本目（速報・選び方ガイド） | 1時間 |
| 木 | 3本目（まとめ・比較） | 2時間 |
| 金 | 4本目（レビューのドラフト） | 1.5時間 |
| 土 | 5本目（レビュー仕上げ） + 翌週ネタ仕込み | 2時間 |
| 日 | 完全休養（執筆禁止） | — |

**合計**: 週 8.5 時間程度。本業がある人間でも維持できる範囲。

## 記事タイプ別テンプレ

### レビュー記事（最重要・CV高）

```
1. 結論（買い / 買わない の一行）
2. 悪い知らせから（短所・落とし穴）
3. 検証環境・用途
4. 具体的な良かった点（3-5項目）
5. 気になった点（2-3項目）
6. こんな人に向く / 向かない
7. 結論（評価点付き）
8. 購入リンク（PriceComparison 自動表示）
```

### まとめ・比較記事（SEO強）

```
1. 結論（一行で「これがおすすめ」）
2. 選定基準（3-5個の判断軸）
3. ランキング or 比較表
4. 各製品の解説（300字程度ずつ）
5. 用途別おすすめ（初心者向け / プロ向け / 予算別）
6. まとめ
```

### ニュース記事（即効性・ソーシャル流入）

```
1. 製品概要（一段落）
2. スペック表（簡潔に）
3. 既存品との比較
4. 発売日・価格・予約リンク
5. 個人的所感（1-2段落）
```

### 選び方ガイド（ロングテール・CV高）

```
1. 「○○選びで失敗しないために」（一段落）
2. 判断軸の解説（3-5個）
3. 価格帯別の選び方
4. おすすめ製品の紹介（3-5製品）
5. よくある質問（FAQ）
```

### セール情報（リピーター獲得）

```
1. セール概要（期間・割引率・対象）
2. 注目商品リスト（3-5個）
3. セール終了までのカウントダウン
4. 購入リンク
```

## 品質チェックリスト（公開前）

- [ ] タイトルが 32 文字以内
- [ ] description が 120 文字前後
- [ ] heroImage が設定されている
- [ ] category が正しく設定されている
- [ ] tags が3つ以上
- [ ] 内部リンクが2つ以上ある（関連記事への誘導）
- [ ] アフィリエイトリンクが少なくとも1つ設定されている
- [ ] 「結論」が記事の最初の段落にある
- [ ] 数値・スペックは複数ソースで確認
- [ ] `npm run build` が通る

## 禁止事項（自分への戒律）

- [ ] **AI で全文生成して即公開しない**
  Google のスパムポリシーに抵触する。AI でドラフトを作っても、必ず人間が手を入れる。

- [ ] **検証していないことを「確認済み」と書かない**
  「ここまでは確認済み、ここからは未検証」を毎回書く（Patch の戒律）。

- [ ] **アフィリンクを過剰に貼らない**
  記事1本あたり購入リンクは 1〜2セクション。本文にバラまかない。

- [ ] **古い情報を放置しない**
  3ヶ月ごとに既存記事を見直し、価格・スペック・在庫情報を更新する。
