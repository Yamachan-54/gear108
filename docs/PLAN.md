# gear108 — 1年ロードマップと収益化戦略

## 前提と目標

- **目標**: 1年（12ヶ月）で月10万円の収益
- **執筆ペース**: 平均週5本（260本/年）
- **テーマ**: エンジニア向け最新ガジェット
- **収益モデル**: Amazon/楽天アフィ + 高単価ASP + AdSense（複合型）

## 収益分解（月10万到達時の想定内訳）

| 収益源 | 月額目標 | 必要条件 |
|--------|---------|---------|
| Amazonアソシエイト | 1.5〜2万 | 月3〜5万PV / 紹介料率2〜4% |
| 楽天アフィリエイト | 1.5〜2万 | Amazon と並列で誘導 |
| 高単価ASP（A8.net、もしも、バリューコマース） | 3〜5万 | プログラミングスクール / SaaS / 転職案件 |
| AdSense | 1〜2万 | 月3〜5万PV |
| **合計** | **7〜11万** | — |

> **注意**：上記は一般論ベースの想定。実数値は記事の質・SEO順位・季節性に強く依存し、保証はできない。**ここまでは確認済み、ここからは未検証**。

## 1年ロードマップ

### 月 1（基盤構築期）

- [x] サイト基盤（Astro + Tailwind + Cloudflare Pages）
- [ ] ロゴ / OGP画像 / favicon
- [ ] Google Analytics 4 + Search Console 設定
- [ ] 独自ドメイン取得（`.com` または `.dev` 推奨）
- [ ] 初期記事 20 本（各カテゴリ最低2本ずつ網羅）
- [ ] プライバシーポリシー / 運営者情報ページ

### 月 2-3（クラスター完成期）

- 累計 70 本まで
- ASP 申請（A8.net、もしも、バリューコマース、Amazonアソシエイト、楽天）
- カテゴリ別ピラーページ整備
- 内部リンク戦略の実装

### 月 4-6（SEO育成期）

- 累計 130 本まで
- 検索順位育成（記事の更新・追記による鮮度維持）
- メルマガ / X アカウント運用開始
- **目標**: 月収 1〜3万円達成

### 月 7-9（最適化期）

- 累計 200 本まで
- 高単価ASP記事の重点投下（プログラミングスクール、SaaS無料体験）
- リライト計画（順位が伸び悩む記事を改善）
- **目標**: 月収 3〜5万円達成

### 月 10-12（収益化加速期）

- 累計 260 本まで
- 季節商戦（年末セール、新生活、Black Friday）対応記事
- 比較記事の強化（CV率高い）
- **目標**: 月収 7〜10万円達成

## 記事タイプ別の役割

| タイプ | 強み | 戦略 |
|-------|------|------|
| レビュー | CV率高い、信頼性 | 実機の写真必須、長期使用感重視 |
| まとめ・比較 | 検索ボリューム大 | 「○選」「比較」「おすすめ」キーワード |
| ニュース | 即効性、SNS拡散 | 公式発表後24時間以内が勝負 |
| 選び方ガイド | ロングテール、CV高 | 初心者キーワード狙い |
| セール情報 | リピーター獲得 | 期間限定、緊急性 |

## SEO 戦略の基本

1. **キーワード選定**: 「製品名 + レビュー」「製品名 + 比較」「カテゴリ + おすすめ」
2. **タイトル設計**: 32文字以内、数字を含む、ベネフィット明示
3. **内部リンク**: 関連記事への双方向リンクを必ず設置
4. **更新頻度**: 古い記事は3ヶ月ごとにリライト、価格・在庫情報を更新
5. **画像最適化**: WebP 必須、alt テキスト必須、Astro Image で自動最適化

## 失敗ケースの想定（事前に潰しておく）

- **AIで量産した薄い記事ばかり** → Google スパム判定でドメイン死亡
- **アフィリンクを盛りすぎ** → CTR は上がるが信頼性低下
- **更新が止まる** → 1年後の月10万到達が遠のく
- **記事が散漫** → 内部リンクが効かず、サイト全体の評価が伸びない

## 撤退基準

以下に該当する場合、戦略を見直す：

- 6ヶ月で月収1万円に到達しない（SEO戦略の根本的見直し）
- 3ヶ月連続で執筆ペースが週3本を下回る（運用設計の修正）
- ドメイン全体のインデックスが急減（スパム判定の疑い）
